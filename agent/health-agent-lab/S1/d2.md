## 1. 程序结构：从 main 说起

**Java 的一切代码都写在「类」里**，程序入口是一个固定签名的 `main` 方法：

```java
public class SyntaxBasicsDemo {              // 类名必须与文件名一致（.java）
    public static void main(String[] args) { // 入口：固定写法，先记住
        System.out.println("Hello, Java");
    }
}
```

- 【TS 对照】TS/JS 允许顶层代码直接执行；Java 必须有个"壳"（类 + main）
- `System.out.println` ≈ `console.log`（`println` 自动换行，`print` 不换行）

**运行方式的两种姿势**：

```powershell
# 传统两步：编译 + 运行（新 JDK 项目实际由构建工具代劳）
javac SyntaxBasicsDemo.java   # 生成 SyntaxBasicsDemo.class
java SyntaxBasicsDemo

# JDK 11+ 单文件直接运行（学习期最方便）
java SyntaxBasicsDemo.java
```

> 回顾 d1.md：`javac` 的角色 ≈ `tsc`，编译产物 `.class` 由 JVM 执行。

## 2. 变量与类型系统

### 2.1 基本类型（8 种）—— Java 的数字是"细分"的

| 类型 | 说明 | 【TS 对照】 |
|---|---|---|
| `byte` / `short` | 小整数（很少直接用） | 无 |
| `int` | 最常用整数（约 ±21 亿） | `number`（整数场景） |
| `long` | 超大整数，字面量加 `L` | `number`（大整数场景） |
| `float` | 小数，字面量加 `f`（很少用） | `number` |
| `double` | 最常用小数 | `number` |
| `char` | 单个字符，单引号 `'A'` | 无（TS 用长度 1 的 string） |
| `boolean` | `true` / `false` | `boolean` |

```java
int age = 25;
long population = 8_100_000_000L;  // 下划线只是给人读的，编译时忽略
double price = 19.9;
boolean vip = true;
char grade = 'A';
```

### 2.2 引用类型：String 与对象

- 基本类型：变量直接存"值"；引用类型：变量存"地址"，实际对象在堆上
- `String` 是**引用类型**（不是基本类型），因此：
  1. 字符串比较必须用 `equals()`，**不能用 `==`**（`==` 比的是地址）★ 高频考点
  2. 字符串**不可变**（每次"修改"都产生新字符串）

```java
String a = new String("abc");
String b = new String("abc");
System.out.println(a == b);        // false —— == 比引用地址
System.out.println(a.equals(b));   // true  —— equals 比内容
```

### 2.3 var 与 final

```java
var city = "杭州";        // 类型推断（Java 10+）【TS 对照】let 的推断
final double PI = 3.14;   // 常量【TS 对照】const
```

> 注意：`var` 只能用于**局部变量**；字段、方法参数不能省类型。

### 2.4 装箱与拆箱（前端最容易忽略的坑）

- 每个基本类型都有对应**包装类**：`int ↔ Integer`、`double ↔ Double`…
- 泛型集合（如 `List<Integer>`）只能装包装类，自动装箱/拆箱是语法糖：

```java
Integer boxed = 100;   // 自动装箱
int unboxed = boxed;   // 自动拆箱
```

> 小坑：两个 `Integer` 用 `==` 比较，-128~127 内因缓存返回 true，范围外返回 false —— **包装类型比较永远用 `equals`**。

## 3. 字符串常用操作

```java
String s = "Hello, Java World";

s.length()                  // 长度（是方法，要括号！）【TS】s.length 是属性
s.substring(7, 11)          // 截取 [7,11) 左闭右开 【TS】slice
s.indexOf("Java")           // 查找位置
s.replace("World", "Agent") // 替换
s.contains("Java")          // 包含【TS】includes
s.split(",")                // 拆分 -> String[]【TS】split
String.join(" | ", arr)     // 拼接【TS】arr.join(" | ")
s.toUpperCase()             // 转大写
s.trim()                    // 去首尾空格
```

**拼接三选一**：

```java
"你好，" + name                              // 少量拼接
String.format("我是%s，今年%d岁", name, age)   // 格式化：%s 字符串 / %d 整数 / %f 小数
"Hello %s".formatted(name)                   // Java 15+ 简写
```

**文本块（Java 15+）**——多行字符串，替代一堆 `\n`：

```java
String report = """
        项目：AI 健康管家
        阶段：S1
        """;
```

## 4. 数组

```java
int[] nums = new int[5];          // 定长数组，默认全 0
int[] preset = { 3, 1, 4, 1, 5 }; // 字面量初始化

nums[0] = 10;        // 访问【TS】arr[0]
preset.length        // 长度是「属性」不是方法（与字符串的 length() 不同！）
```

- 遍历：`for (int n : preset)`（增强 for）【TS 对照】`for (const n of preset)`
- 工具类 `Arrays`：`sort()` / `toString()` / `copyOf()` / `binarySearch()`
- **定长是硬限制**（不能 push）——需要动态增删请用 `ArrayList`（见第 7 章）

## 5. 运算符与流程控制

大部分与 TS 相同：`+ - * / %`、比较、`&& || !`、三元 `? :`、自增自减等。

- 整数相除**截断**：`7 / 2 == 3`（要小数用 `7 / 2.0`）
- `==` 对基本类型比值；对对象比地址（对象比较用 `equals`）

```java
// if / else / while / for / break / continue —— 与 TS 一致
// switch 传统写法：每个 case 要 break，否则会"穿透"
switch (level) {
    case "A": ...; break;
    default: ...
}

// switch 表达式 + 箭头（Java 14+）：不需要 break，可直接赋值
String dayType = switch (day) {
    case 1, 2, 3, 4, 5 -> "工作日";
    case 6, 7 -> "周末";
    default -> "非法日期";
};
```

## 6. 面向对象：类 / 继承 / 多态 / 接口

> 配套示例：`examples/OopDemo.java`

### 6.1 类与封装

```java
public class Animal {
    private String name;    // private = 仅本类可访问（封装）
    protected int age;      // protected = 子类也可访问

    public Animal(String name, int age) {  // 构造器：new 时执行
        this.name = name;   // this 区分"字段"与"参数"
        this.age = age;
    }

    public String getName() { return name; }          // getter
    public void setName(String name) { this.name = name; } // setter

    public void say() { System.out.println(name + " 发出声音"); }
}
```

【TS 对照】类、构造器、`this`、访问修饰符与 TS class 几乎一致；差别主要在于**字段要显式声明类型**、getter/setter 是 Java 社区惯例。

### 6.2 继承与多态

```java
class Dog extends Animal {          // 单继承（TS 也是单继承）
    public Dog(String name, int age) { super(name, age); }  // 先调父类构造器

    @Override                       // 注解：声明"我在重写父类方法"，写错会报错
    public void say() { System.out.println(getName() + " 汪汪汪"); }
}

Animal a = new Dog("旺财", 3);   // 多态：父类引用指向子类对象
a.say();                        // 运行时调用 Dog 重写后的 say()
```

- **重写 Override**：子类改父类行为（加 `@Override` 让编译器检查）
- **重载 Overload**：同名方法不同参数（与 TS 可选参数/联合类型是不同思路）

### 6.3 抽象类 vs 接口

| | 抽象类 `abstract class` | 接口 `interface` |
|---|---|---|
| 定位 | "是什么"（is-a），可含字段和实现 | "能做什么"（can-do），行为约定 |
| 继承 | 单继承 | 可以多实现 |
| 方法 | 抽象 + 具体方法 | 抽象方法（Java 8+ 也允许 default 方法） |
| 【TS 对照】 | ≈ TS 抽象 class | ≈ TS interface **但定位完全不同**：TS interface 描述"类型的形状"，Java interface 定义"行为契约" |

```java
abstract class Animal {          // 抽象类：不能 new
    public abstract void say();  // 抽象方法：子类必须实现
}

interface Swimmable {
    void swim();                 // 实现类必须提供
}

class Duck extends Animal implements Swimmable {  // 继承 + 多实现
    @Override public void say() { /* ... */ }
    @Override public void swim() { /* ... */ }
}
```

### 6.4 三个常用概念

- **Object**：所有类的老祖宗，常重写 `toString()` / `equals()` / `hashCode()`
- **static**：属于「类」而非「对象」（如 `Math.max`、`Integer.parseInt`）
- **record**（Java 16+）：一行声明不可变数据类，自动生成构造器/访问器/equals/toString：

```java
record Point(int x, int y) { }
Point p = new Point(3, 4);
p.x();                   // 访问器是 x()，不是 getX()
System.out.println(p);   // Point[x=3, y=4]
```

> 【TS 对照】record ≈ `type Point = { x: number; y: number }` + 自动生成的相等性与打印，用来消灭"一堆 getter/setter"的样板代码。

## 7. 集合框架：List / Map / Set

> 配套示例：`examples/CollectionsDemo.java`

### 7.1 List（有序、可重复）

| 实现 | 底层 | 特点 | 适用 |
|---|---|---|---|
| `ArrayList` | 动态数组 | 随机访问快 O(1)；中间插入/删除慢 O(n) | **默认首选**（绝大多数场景） |
| `LinkedList` | 双向链表 | 随机访问慢 O(n)；头尾插入/删除快 O(1) | 频繁头尾操作（队列） |

```java
List<String> list = new ArrayList<>();
list.add("Java");
list.add(1, "Go");        // 指定位置插入
list.get(0);              // 取【TS】arr[0]
list.size();              // 长度【TS】arr.length
list.contains("Java");    // 包含【TS】includes
list.remove("Go");        // 按值删除
list.set(0, "JAVA");      // 替换
for (String s : list) { } // 遍历
list.sort(Comparator.naturalOrder());  // 排序
```

> ★ 验收目标：**能解释 ArrayList vs LinkedList 的取舍**（见上表）。

### 7.2 Map（键值对）

```java
Map<String, Integer> stock = new HashMap<>();
stock.put("苹果", 10);
stock.get("苹果");                 // 取值（不存在返回 null）
stock.getOrDefault("西瓜", 0);     // 不存在给默认值
stock.containsKey("苹果");
for (Map.Entry<String, Integer> e : stock.entrySet()) {  // 遍历【TS】Object.entries()
    e.getKey(); e.getValue();
}
```

变体：`TreeMap`（按 key 排序）、`LinkedHashMap`（保持插入顺序）。

### 7.3 Set（去重）

```java
new HashSet<>();        // 无序去重
new LinkedHashSet<>();  // 去重 + 保持插入顺序（常用）
new TreeSet<>();        // 去重 + 自动排序
```

【TS 对照】≈ `[...new Set(arr)]` 去重。

### 7.4 快速创建与迭代陷阱

```java
List.of("a", "b")          // 快速创建【只读】列表
Map.of("k1", 1, "k2", 2)   // 快速创建【只读】Map

// 陷阱：遍历中删除元素要用 Iterator，不能直接 list.remove()
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    if (it.next().equals("x")) it.remove();  // 正确姿势
}
```

## 8. 泛型

> 配套示例：`examples/CollectionsDemo.java`

```java
// 泛型方法：<T> 是"类型参数"，编译期检查 + 免强制转换
static <T extends Comparable<T>> T max(T a, T b) {
    return a.compareTo(b) >= 0 ? a : b;
}
max(3, 7);      // T 推断为 Integer
max("a", "b");  // T 推断为 String

List<String> names = new ArrayList<>();
names.add("小米");
// names.add(123);   // ← 编译期直接报错（TS 的泛型同理）
```

【TS 对照】`List<String>` ≈ `Array<string>`；`Map<String, Integer>` ≈ `Record<string, number>`。

> 一句话原理：Java 泛型只在**编译期**生效，运行时被"擦除"（类型擦除）——所以不能 `new T()`、不能 `instanceof T`。

## 9. 异常处理

> 配套示例：`examples/ExceptionDemo.java`

```java
try {
    int r = divide(10, 0);            // 可能抛异常
} catch (ArithmeticException e) {     // 捕获并处理
    System.out.println("出错：" + e.getMessage());
} finally {
    System.out.println("无论如何都执行");  // 常用于释放资源
}
```

**异常体系**：

```
Throwable
├── Error                  （严重错误，一般不处理，如 OutOfMemoryError）
└── Exception
    ├── RuntimeException 及子类 → 「非受检异常」：编译不强制处理（如 NullPointerException）
    └── 其他                  → 「受检异常」：编译期强制 try-catch 或 throws
```

- 【TS 对照】TS 的异常"随意"；Java 的**受检异常**必须显式处理——这是后端代码里"层层 try/catch"的原因
- **try-with-resources**（自动关资源，比 finally 优雅）：

```java
try (FakeConnection conn = new FakeConnection()) {
    conn.query();
} // 离开 try 自动 close()
```

- 自定义异常：`class InvalidInputException extends Exception { ... }`

## 10. Lambda 与函数式接口

> 配套示例：`examples/LambdaStreamDemo.java`

```java
Runnable task = () -> System.out.println("执行");           // 无参
Function<Integer, Integer> doubleIt = x -> x * 2;           // 有参有返回
Predicate<Integer> isPositive = x -> x > 0;                 // 返回 boolean
Consumer<String> print = s -> System.out.println(s);        // 只消费
```

- 【TS 对照】`x -> x * 2` ≈ `(x) => x * 2`，语法几乎一样
- **函数式接口**：只有一个抽象方法的接口（上面这些就是）——才能用 Lambda
- **方法引用**：`System.out::println` 是 `s -> System.out.println(s)` 的简写

## 11. Stream API（重点！）

> 配套示例：`examples/LambdaStreamDemo.java`

像写 JS 数组方法一样处理集合，风格与 `filter/map/reduce` 高度一致：

```java
List<String> adultNames = users.stream()
        .filter(u -> u.age() >= 18)      // 筛选【TS】filter
        .map(User::name)                 // 映射【TS】map
        .collect(Collectors.toList());   // 收集成 List

users.stream().count();                                       // 计数
users.stream().sorted(Comparator.comparingInt(User::age));    // 排序
users.stream().collect(Collectors.groupingBy(User::city));    // 分组（TS 要手写 reduce）
users.stream().mapToInt(User::age).sum();                     // 求和
users.stream().anyMatch(u -> u.age() >= 18);                  // 【TS】some
users.stream().allMatch(...);                                 // 【TS】every
users.stream().max(Comparator.comparingInt(User::age));       // 最大值 -> Optional
```

> 与 JS 的区别：Stream 是**惰性**的——遇到 `collect` / `forEach` 等"终止操作"才真正执行。

## 12. Optional

> 配套示例：`examples/LambdaStreamDemo.java`

```java
Optional.ofNullable(stock.get("西瓜"))   // 可能为 null 的值
        .orElse(0)                       // 空则给默认值【TS】??
        .map(n -> "库存: " + n)           // 有值时转换
        .ifPresent(System.out::println); // 有值才消费
```

- 【TS 对照】解决同类问题：`??` / `?.` 的空值处理
- 用途：方法返回值可能为空时，用 `Optional` 替代直接返回 `null`，让调用方"被提醒"

## 13. TS ↔ Java 速查对照表

| 概念 | TypeScript | Java |
|---|---|---|
| 声明变量 | `let x = 1` / `const x = 1` | `var x = 1;` / `final int x = 1;` |
| 数字 | `number` | `int` / `long` / `double` … |
| 字符串长度 | `s.length`（属性） | `s.length()`（方法） |
| 字符串比较 | `===` | `equals()` |
| 模板字符串 | `` `你好 ${name}` `` | `String.format("你好 %s", name)` |
| 数组 | `arr.push()` 动态 | 定长 `int[]`；动态用 `ArrayList` |
| 遍历数组 | `for (const x of arr)` | `for (int x : arr)` |
| 字典/对象 | `{ k: v }` / `Record<K,V>` | `Map<K,V>`（数据结构用 class/record） |
| 去重 | `[...new Set(arr)]` | `new LinkedHashSet<>(list)` |
| 筛选/映射 | `arr.filter().map()` | `stream().filter().map()` |
| 空值 | `??` / `?.` | `Optional` / `orElse` |
| 异常 | `try/catch`（随意） | `try/catch` + 受检异常强制处理 |
| 泛型 | `Array<T>` | `List<T>`（编译期检查 + 类型擦除） |
| 打印 | `console.log` | `System.out.println` |
